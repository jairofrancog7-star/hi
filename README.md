# Entrena como las grandes · fútbol femenil Sub-17

Guía extensa y material práctico de entrenamiento para fútbol femenil.
La versión web está preparada para **celular Android**, funciona como un solo HTML, conserva las posturas, diagramas y QR, usa **azul cielo** como tema claro y tiene **botón manual de modo claro / oscuro**.

## Abrir en el celular

Usa:

**https://htmlpreview.github.io/?https://github.com/jairofrancog7-star/hi/blob/main/index.html**

La raíz `main/index.html` es la fuente que utiliza esa vista. Por eso no debe sustituirse por la antigua página de 15 fichas.

## Diseño móvil

- tema claro azul cielo, sin fondo blanco agresivo;
- botón **◐ Tema** para alternar manualmente entre claro y oscuro;
- preferencia de tema recordada en el dispositivo;
- navegación responsive;
- visores ampliados sin superposiciones;
- posturas y dibujos técnicos conservados;
- botones grandes para Android;
- QR y enlaces de demostración;
- recursos principales disponibles sin conexión una vez guardado el HTML.
