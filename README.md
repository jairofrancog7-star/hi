# Entrena como las grandes · fútbol femenil Sub-17

Versión móvil V3 de la guía para las alumnas.

## Abrir la guía

**Vista para celular**
https://htmlpreview.github.io/?https://github.com/jairofrancog7-star/hi/blob/main/index.html

## Qué incluye esta versión

- 58 fichas de entrenamiento.
- Guía web enfocada primero a Android/celular.
- Fondo azul cielo.
- Botón flotante de modo claro / oscuro.
- “Ver en grande” con apertura compatible por CSS `:target`, sin depender de JavaScript.
- “Activar movimiento” con interruptor CSS; el permiso del sensor del teléfono es solo una mejora opcional.
- Números de ficha convertidos en badges compactos para que no sobresalgan de la pantalla.
- Academia visual nueva con dibujos tutoriales originales:
  - golpeo potente;
  - pase interior;
  - control orientado;
  - cabeceo;
  - defensa 1 contra 1;
  - conducción y cambio de ritmo;
  - tiro con efecto;
  - escaneo y toma de decisiones.
- Bloque especial de defensa para centrales, laterales y duelos 1v1.
- Ideas de juego inspiradas en rasgos técnicos de Mitoma, Haaland, Cristiano Ronaldo, Fede Valverde, Toni Kroos, Messi y Aitana Bonmatí.
- Rutina visual y mental previa al partido.
- Catálogo visual interno de los 58 ejercicios. `ejercicios.json` queda como descarga opcional para datos.
- Videoteca externa con 13 referencias TikTok aportadas por el entrenador y QR individuales.
- Enlaces de apoyo técnico de FIFA Training Centre.

## Archivos que cambia este paquete

Solo sustituye:

- `index.html`
- `README.md`
- `guia-sub17/dist/index.html`

Los PDF de 169 páginas y las 58 láminas no se vuelven a subir porque ya están publicados y no cambiaron en esta revisión.

## Seguridad

El script crea un respaldo de los tres archivos antes de reemplazarlos y después hace un único commit y `git push origin main`.
